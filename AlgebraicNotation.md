# Algebraic notation
**Source:** [wikipedia](https://en.wikipedia.org/wiki/Algebraic_notation_(chess))

---
### Square Notation
![Chess move notation](https://thumb.wikimedia.org/wikipedia/commons/thumb/b/b6/SCD_algebraic_notation.svg/250px-SCD_algebraic_notation.svg.png?utm_source=en.wikipedia.org&utm_campaign=parser&utm_content=thumbnail)

Each square on the chessboard is identified by a unique coordinate consisting of a letter (a-h) for the file and a number (1-8) for the rank. For example, `g5` refers to the square in the g-file and 5th rank.

### Piece Notation
| Symbol | Piece |
| --- | --- |
| `K` | King |
| `Q` | Queen |
| `R` | Rook |
| `B` | Bishop |
| `N` | Knight |
| (none) | Pawn |

**Disambiguating moves**

When two identical pieces can move to the same square, the originating file or rank is specified to avoid ambiguity. For example:
- `Nbd2` indicates the knight from the b-file moves to d2.
- `R1e2` indicates the rook from the first rank moves to e2.

### Move Notation
| Symbol | Meaning |
| --- | --- |
| `x` | Indicates a capture. |
| `+` | Indicates a move that is a check. |
| `#` | Indicates a move that is checkmate. |
| `O-O` | Kingside castling. |
| `O-O-O` | Queenside castling. |



### Promotion

When a pawn reaches the eighth rank, it can be promoted to any other piece (except a king). The move is indicated by appending `=` followed by the piece symbol. For example:
- `e8=Q` indicates a pawn moves to e8 and is promoted to a queen.
- `b1=N` indicates a pawn moves to b1 and is promoted to a knight.

### Evaluation symbols
| Symbol | Meaning |
| --- | --- |
| `!!` | A brilliant—and usually surprising—move |
| `!` | A very good move |
| `!?` | An interesting move that may not be the best |
| `?!` | A dubious move that is not easily refutable |
| `?` | A bad move; a mistake |
| `??` | A blunder (i.e. critically bad mistake) |
| `⌓` | A better move than the one played |
| `□` | A forced move; the only reasonable move, or the only move available |
| `TN or N` | A theoretical novelty |

Symbol	Meaning
| Symbol | Meaning |

| `+/= or ⩲` | White has a slight plus. |
| `=/+ or ⩱` | Black has a slight plus. |

| `−/+ or ∓` | Black has a clear plus. |

| `−+` | Black has a winning advantage. |
